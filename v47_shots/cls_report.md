## 원인과 수정

1. **서드파티 렌더 블로킹 CSS** — `cdn.jsdelivr.net` Pretendard 스타일시트가 사이트 CSS보다 먼저 있어, 스타일이 도착하기 전 화면이 그려졌습니다(데스크톱 `/stays` 0.338). 폰트 92청크+CSS를 `assets/fonts/`로 자체 호스팅하고 사이트 CSS 뒤에 두었습니다.
2. **폰트 교체(FOUT) 줄바꿈** — Pretendard가 늦게 오면 대체 폰트로 먼저 그려져 긴 리드 문단이 6줄→5줄로 바뀌며 28px 이동. `@font-face "Pretendard Fallback"`에 실측 비율 `size-adjust:93.1%`를 적용해 대체 폰트 폭을 맞췄습니다(실제 표시 폰트는 그대로 Pretendard).
3. **JS 삽입 콘텐츠** — 홈 `#fdList`(파인더 추천 3곳)가 비어 있다가 2초 뒤 채워지며 1,122px 삽입(모바일 홈 0.078). 기본 상태를 `build.py: finder_default_view()`로 서버에서 미리 그립니다. 내 여행 D-Day 띠는 헤더 아래 흐름에 끼어들어 모든 페이지 본문을 38px 밀었습니다(재방문 0.027~0.144). 화면 아래 고정 필로 바꿔 레이아웃에 영향이 없게 했습니다.
