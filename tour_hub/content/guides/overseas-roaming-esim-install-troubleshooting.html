eSIM은 공항에 내려서 켜면 되는 줄 알지만, 실제로 안 터지는 경우의 90%는 설정 세 가지 중 하나입니다. ① 데이터 회선이 아직 한국 SIM으로 되어 있거나 ② eSIM 회선의 데이터 로밍이 꺼져 있거나 ③ eSIM 회선 자체가 꺼져 있는 경우입니다. 이 세 개를 1분 안에 확인하면 대부분 해결됩니다.

도시별 숙소·동선은 오사카·교토·도쿄·후쿠오카·다낭·방콕·타이베이 페이지와 함께 보세요.

이 글은 2026년 11월 기준 아이폰(iOS 18 이상)과 갤럭시(안드로이드 14 이상)의 설정 경로, 트립픽이 확인한 eSIM 상품가(일본 1일 590원·3일 16,830원 등), 통신사 로밍 1일 9,900원을 기준으로 썼습니다. 설치 전 준비는 eSIM·로밍·보험 비교 글에, 나라별 상품 비교는 일본 eSIM·베트남 eSIM 글에 있습니다.

주의할 점은 한국 SIM의 데이터 로밍을 켜면 안 된다는 것입니다. eSIM을 쓰면서 한국 번호로 전화·문자를 받으려면 한국 SIM은 ‘통화·문자용’으로만 살려 두고, 데이터는 eSIM으로 보냅니다. 둘 다 데이터 로밍을 켜면 한국 SIM이 먼저 잡아 요금이 나갈 수 있습니다.

아이폰 설정 — 이 4개만 보면 됩니다

아이폰은 설정 → 셀룰러에서 회선별로 나뉩니다. eSIM을 추가하면 회선이 두 개로 보이고, 각 회선 아래에 ‘셀룰러 데이터’, ‘데이터 로밍’, ‘이 회선 사용’이 따로 있습니다.

  • 셀룰러 데이터 — eSIM 회선을 선택합니다. 이게 한국 SIM으로 되어 있으면 데이터가 안 터집니다.
  • 기본 음성 회선 — 한국 SIM을 선택합니다. 은행·본인인증 문자를 받아야 하기 때문입니다.
  • 셀룰러 데이터 전환 허용 — 끕니다. eSIM이 약할 때 한국 SIM으로 데이터를 넘겨 로밍 요금이 나가는 것을 막습니다.
  • 데이터 로밍 — eSIM 회선에서만 켭니다. 한국 SIM 회선은 끕니다.

경로는 기기·iOS 버전에 따라 조금 다릅니다. iOS 18 기준으로 설정 → 셀룰러 → (eSIM 회선) → 데이터 로밍이고, 회선 이름을 “일본 eSIM”처럼 바꿔 두면 현지에서 헷갈리지 않습니다. eSIM 추가는 설정 → 셀룰러 → eSIM 추가에서 QR을 스캔하거나 판매처의 활성화 코드를 입력합니다.

‘셀룰러 데이터 전환 허용’은 꼭 끄세요

이 옵션이 켜져 있으면 eSIM 신호가 약할 때 아이폰이 자동으로 한국 SIM의 로밍 데이터를 씁니다. 하루 1만원 안팎의 로밍 요금이 붙는 이유가 대부분 여기입니다. eSIM을 쓰는 동안에는 끔이 기본값이라고 생각하세요.

갤럭시 설정 — SIM 관리자에서

갤럭시는 설정 → 연결 → SIM 관리자에서 회선을 관리합니다. eSIM을 추가하면 ‘SIM 1(한국)’, ‘SIM 2(eSIM)’처럼 두 개가 보입니다.

  • 모바일 데이터 — eSIM(SIM 2)을 선택합니다.
  • 통화 — 한국 SIM을 선택합니다. 통화·문자는 한국 번호로.
  • 데이터 로밍 — eSIM 회선에서 켭니다.
  • 자동 데이터 전환 — 끕니다. 아이폰의 ‘셀룰러 데이터 전환 허용’과 같은 기능입니다.

eSIM 추가는 설정 → 연결 → SIM 관리자 → eSIM 추가에서 QR을 스캔합니다. 기기마다 메뉴 이름이 ‘SIM 카드 관리자’, ‘SIM 및 네트워크’로 다를 수 있지만, 찾는 항목은 같습니다. 갤럭시 S20 이후 모델 대부분이 eSIM을 지원하지만, 국내 출시 보급형 일부와 중국판 아이폰은 지원하지 않습니다. 가장 확실한 확인은 설정에 ‘eSIM 추가’ 메뉴가 보이는지입니다.

설치는 됐는데 안 될 때, 원인 7가지

  1. 데이터 로밍이 꺼져 있음 — 가장 흔합니다. eSIM은 현지 통신사 망을 빌려 쓰므로 ‘로밍’이 필수입니다. 한국 SIM의 로밍과 헷갈리지 마세요.
  2. 데이터 회선이 한국 SIM — eSIM을 설치만 하고 데이터 회선을 바꾸지 않은 경우입니다.
  3. APN이 비어 있음 — 대부분 자동 설정이라 직접 넣지 않아도 됩니다. 안 될 때만 판매처가 보낸 APN 값을 이름·APN·사용자 이름·비밀번호 칸에 그대로 입력하세요. 임의로 다른 값을 넣으면 더 안 됩니다.
  4. 수동 네트워크 선택 — 자동 선택이 현지 통신사가 아닌 망을 잡는 경우가 있습니다. 설정 → 셀룰러 → 네트워크 선택에서 자동을 껐다가 다시 켜 보세요.
  5. 요금제 활성화 대기 — QR을 스캔해도 통신사 시스템에 등록되기까지 5~10분 걸리는 상품이 있습니다. 공항을 걸어 나오면서 기다리면 대개 붙습니다.
  6. 데이터 절약·저전력 모드 — 백그라운드 데이터를 막아 지도·메신저가 안 되는 경우가 있습니다. 저전력 모드를 끄고 다시 확인하세요.
  7. VPN·프라이빗 릴레이 — 켜져 있으면 일부 앱이 인터넷을 못 잡습니다. eSIM 첫 연결 때는 끄고 확인하는 편이 빠릅니다.
“LTE만 뜨고 5G가 안 뜬다”

5G는 현지 통신사·기기 조합에 따라 안 잡힐 수 있습니다. LTE로도 지도·메신저·결제는 충분합니다. 5G를 고집하다 설정을 바꾸면 오히려 데이터가 끊기는 경우가 많으니, 인터넷이 되면 그대로 쓰세요.

통화비 폭탄 막는 설정

eSIM은 데이터 전용 상품이 많습니다. 한국 번호를 살려 두면 전화·문자는 로밍 요금이 붙습니다. 받는 전화도 무료가 아닙니다. 다음 네 가지만 해 두면 청구서가 튀지 않습니다.

  • 한국 SIM 데이터 로밍 끄기 — 데이터는 eSIM, 음성만 한국 SIM.
  • ‘데이터 전환 허용’ 끄기 — 아이폰·갤럭시 모두.
  • 모르는 번호는 받지 않기 — 해외에서 오는 스팸 전화를 받으면 통화료가 나갑니다. 부재중 알림으로 확인하세요.
  • 연락은 카카오톡·와이파이 통화로 — 숙소 와이파이에서 통화하면 요금이 없습니다. 급할 때만 한국 번호로 전화하세요.
문자 인증은 한국 SIM으로 옵니다

은행·정부24·항공사 앱 인증 문자는 한국 번호로 옵니다. eSIM을 쓰면서도 한국 SIM을 ‘통화·문자’ 회선으로 남겨 두면 수신할 수 있습니다. 다만 문자 수신에도 로밍 요금이 붙는 요금제가 있으니, 출국 전 통신사 앱에서 문자 수신 요금을 한 번 확인하세요.

74,480원이면 오사카 주유패스 2일권을 사고 남습니다. 트립픽에서 확인한 상품은 일본 3일 무제한 eSIM 16,830원, 베트남 3일 무제한 eSIM 17,850원입니다(2026-11 확인).

74,480원이면 오사카 주유패스 2일권을 사고 남습니다. 다만 500MB/일 상품은 하루 500MB를 다 쓰면 속도가 128kbps로 떨어집니다. 지도·메신저는 되지만 영상통화·테더링은 어렵습니다. 영상통화를 자주 하거나 노트북을 붙인다면 무제한 상품(3일 14,450~17,850원)이 낫습니다. 데이터 사용량은 출발 전에 설정에서 지난달 하루 평균을 확인하면 판단이 쉽습니다.

QR·삭제·환불 — 되돌릴 수 없는 것

  • QR은 1회용이 대부분입니다. 스캔 전에 화면을 캡처해 두세요. 캡처도 1회용인 상품이 있으니, 설치 후에는 지우지 마세요.
  • ‘eSIM 삭제’를 누르면 재설치가 안 되는 상품이 많습니다. 기기를 초기화하거나 회선을 지우면 환불도 어렵습니다.
  • 설치는 출발 1~2일 전, 집 와이파이에서 — 현지 공항 와이파이는 인증이 끊겨 설치가 실패하는 일이 흔합니다.
  • 설치 후 ‘이 회선 사용’은 끄고 출국 — 켜 두면 한국에서 데이터를 잡아 요금이 나갈 수 있습니다. 도착 후 켭니다.
  • 환불 규정은 상품마다 다릅니다 — 미사용·미설치 상태에서만 환불되는 경우가 많으니, 결제 전 상세페이지의 취소 규정을 확인하세요.

출국 전 3분 체크리스트

  • 기기 eSIM 지원 — 설정에 ‘eSIM 추가’가 보이는지
  • 일수 계산 — 4일이면 1일권 4장 또는 3일+1일
  • 테더링 필요 여부 — 500MB 상품은 핫스팟이 막힌 경우가 많음
  • 통화 필요 여부 — 필요하면 한국 SIM을 음성 회선으로 남김
  • QR 캡처 — 설치 전 화면 저장
  • 설치 시점 — 출발 1~2일 전, 집 와이파이
  • 도착 후 — 데이터 회선 eSIM, 로밍 켜기, 데이터 전환 끄기
같이 보면 좋은 것

eSIM 설치 전 준비물은 D-Day 체크리스트(D-14 eSIM·D-3 짐), 숙소·공항 동선은 찐숙소와 패스 계산기, 결제 카드 비교는 환율 계산기에 있습니다.

한 줄 결론

도착 후 안 터지면 데이터 회선 → eSIM 회선 사용 → 데이터 로밍 순서로 1분 안에 확인하세요. 그래도 안 되면 비행기 모드 10초, 재부팅, QR 재설치 순입니다. 통화비는 한국 SIM 데이터 로밍 끄기 + 데이터 전환 허용 끄기로 막고, 데이터는 eSIM으로 보내면 2인 4일 기준 로밍(79,200원)보다 7만 4천원 이상 쌉니다.
